# Barber Shop Website

Un sito web moderno, responsivo e professionale per un barbiere.

## Struttura del Progetto

```
barber-shop/
├── index.html          # Pagina principale (Home)
├── services.html       # Pagina servizi con prezzi
├── products.html       # Pagina prodotti acquistabili
├── contacts.html       # Pagina contatti e mappa
├── styles.css          # Stile CSS responsivo
└── script.js           # JavaScript interattivo
```

## Come Usare

1. Apri il file **index.html** in un browser moderno (Chrome, Firefox, Safari, Edge)
2. Naviga tra le pagine usando la navbar o i link
3. Il sito è completamente responsivo e funziona su tutti i dispositivi!

## Personalizzazione

### Cambiare i colori
Nel file **styles.css**, modifica le variabili CSS:
```css
:root {
    --primary-color: #1a1a2e;   /* Blu scuro */
    --secondary-color: #16213e; /* Blu più scuro */
    --accent-color: #c9a227;    /* Oro */
}
```

### Cambiare i contenuti
Modifica direttamente i file HTML per cambiare testi, prezzi, orari e contatti.
